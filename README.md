# deep-research

可移植的 [Agent Skill](https://agentskills.io)。做**深度公开调研和竞争情报**。

用户用自然语言说要调研什么（一个产品、一家公司、一条赛道）。主体清楚就直接跑完全程，不要先采访。每次交付一份 PDF 报告。

## 安装

```
mkdir -p .agents/skills
git clone https://github.com/qlin99706-create/deep-research.git .agents/skills/deep-research
```

已经 clone 过：

```
git -C .agents/skills/deep-research pull
```

## 用法

`@deep-research`，或直接说「调研某某」「竞争格局」「做战斗卡」。主体清楚就开跑，不必先说 skill。
